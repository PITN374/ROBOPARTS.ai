DESIGN RULES

Each entity receives a persistent identifier.
Product identity differs from physical-instance identity.
BOM relationships reference component instances.
Compatibility assessments retain missing evidence.
Lifecycle events reference affected components.
Verification status reflects actual evidence.
Missing information does not prove compatibility.
Performance observations include units and provenance.
Organization registration does not establish verification.
Database persistence and access controls require implementation.
